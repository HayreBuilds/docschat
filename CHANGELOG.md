# Changelog

## 1.0.0

- BFS documentation site crawler with same-domain link following
- Local directory walker for Markdown, MDX, RST, HTML files
- NVIDIA nv-embedcode-7b-v1 embeddings with batch ingestion
- Cosine similarity vector search over chunked documents
- Nemotron-Ultra 550B for answer generation with source citations
- Embeddable vanilla JS widget (single script tag)
- CLI: index, serve, and ask commands
- CORS-enabled server for cross-origin widget requests
- Zero runtime dependencies
